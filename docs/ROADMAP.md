# Development direction

The 0.2 release provides a complete small single-player fighting game: two selectable fighters, a three-rival Arcade ladder, Quick Duel, Training, menu and match flow, original graphics and audio, persistent settings, and combat tooling.

Possible future releases can add local two-player versus, per-fighter signature specials, extra arenas, additional animation frames, controller rebinding, an expanded roster, replay recording, and further accessibility options. Network play would require a separate design for deterministic simulation and rollback; it is not part of the current release.
